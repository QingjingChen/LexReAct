# 推理错误的 baseline 题例（检索没问题、事实清楚，错在推理）

从 benchmark 中筛选出 9 道题，比较两个 baseline 和规则引擎的表现：

- **LEGO**：PFC-v3 提示；
- **IRAC**：IRAC v4 提示，与 LEGO 使用**完全相同**的检索结果；
- **规则引擎**：LegalRuleML → DDL。

## 筛选标准

1. **检索没问题**：金标解析引用的民法典条文，全部在 baseline 拿到的 8 条法条之内。
2. **规则能覆盖**：这些条文在规则层中有形式化。
3. **至少一个 baseline 答错**，并且人工核对确认，错误出在推理上。

初筛得到 26 道，人工复核后保留 9 道，排除原因见文末。

## 运行方式

```sh
python src/run_cases.py graph/civil/examples/q558.json -v     # 任一题；-v 打印推理链
```

**两类情况**

- **两个 baseline 都错**：Q526、Q558、Q662、Q504、Q530。
- **只有 IRAC 错**：Q702、Q306、Q583、Q565。同一份检索结果，换一个提示答案就变了，说明推理并不稳定；LEGO 在这几题答对，也不能排除有运气成分。

**每题的选项校验**

- 每道题按选项写出可检验的结论。部分题目还附有**反事实**情形，例如 `q504-cf`（假设设备尚未交付）、`q558-C`（假设胁迫已终止满一年）。改动一条事实，结论随之翻转，以此说明是哪一跳决定了答案。
- 涉及日期的条件，例如“胁迫终止已满一年”，作为事实输入；日期的推算在规则之外完成。

## 为这批题新增的规则

以下 3 条规则均为学理通说，权威标为 `doctrine`：

- `c226-delivery`：买受人已经占有标的物的，买卖合同生效时视为交付（简易交付）。
- `c604-price`：风险由买受人承担时，标的物毁损灭失后，买受人仍须支付价款。
- `c-revoke-against`：撤销权只能向合同相对人主张。
